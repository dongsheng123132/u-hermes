马盘是怎么跑起来的

四个设计决定，决定了它跟"装个软件"不一样

⚡

引擎装本机

运行时展开到本机硬盘缓存目录，U 盘只读不写。U 盘速度慢、寿命有限，脏活让本机干。

💾

数据留 U 盘

对话、配置、技能、记忆全在 U 盘里。插到哪台 Windows 都是同一个你，拔了就走。

👛

设备钱包

服务端签发的凭证，不是硬件指纹算出来的。丢盘能换、能切、能填别人的，余额跟着钱包走。

💳

一点就充值

点一下跳到支付宝 / 微信付款页，客户端不接触支付信息，也不自动扣费。

🛡️

关于签名

启动壳目前没有代码签名证书，Windows SmartScreen 可能会提示"未知发布者"。点「更多信息 → 仍要运行」即可。我们在申请证书。

🍎

不支持 Mac

量产盘用 NTFS 格式（Windows 原生、支持符号链接），macOS 只读。Mac 用户请用同门的 U-DSH 便携版。

常见问题

U-Claw 和 U-Hermes 什么区别？

U-Claw 面向通用 AI 场景和 IM 机器人（QQ/微信/飞书接入）。U-Hermes 面向编程和真·自主 Agent（执行 shell、操作浏览器、读写文件）。两个都装在同一张马盘 U 盘里，按需切换。

换电脑能用吗？

可以。马盘 U 盘绑定账户体系，插哪台 Windows 电脑都是同一个账户和余额。

U 盘坏了怎么办？

联系微信 hecare888 用订单号换新马盘 U 盘，余额会转移。

Mac / Linux 能用吗？

马盘是 Windows 产品，量产盘用 NTFS 格式，macOS 只读、Linux 不保证。想要 Mac 便携 AI，请看同门的 U-DSH 便携版。

杀毒软件拦截 / 没法运行？

启动器是无签名 Electron 应用，360 / 火绒 / Windows Defender 可能拦截。请在杀毒软件里把 U 盘上的对应启动器（如 launcher/U-Hermes.exe / launcher/U-Claw.exe）加白名单。我们在申请代码签名证书，下个版本会解决。

启动后端口被占用？

默认端口 8642 / 8648。如果占用，启动器会自动 +1 避让。如仍有问题，从托盘退出后重启。

退款政策？

非质量问题 7 天内可退（U 盘未使用）。已充值的 AI 余额不可退，但可继续在 cloud.u-claw.org 使用。

开源版和商业版区别？

Hermes Agent 内核是 MIT 开源的，你可以自己装（见上方对照）。马盘卖的是成品：U 盘硬件、启动壳、设备钱包、初始额度、中文教程和售后。开源的程序都在自己手里，我们卖的是一整套不用折腾的体验。

为什么不直接下载软件？

可以，Hermes Agent 本身免费开源。马盘解决的是另外几件事：便携（数据在盘里）、免配置（钱包+额度就位）、中文教程和售后。如果你只想自己折腾，直接去上游仓库装就行。
