How MaPan works

Four design decisions that make it different from "just install the app"

⚡

Engine on the host

The runtime unpacks into a local cache directory. USB sticks are slow and wear out — let the local disk do the work.

💾

Data on the USB

Chats, config, skills and memory stay on the stick. Any Windows machine you plug into is the same you.

👛

Device wallet

Credentials are minted server-side, not derived from hardware fingerprints. Lost stick? Rotate the key, keep the balance.

💳

One-click top-up

Opens the Alipay / WeChat payment page in your browser. The client never handles payment data and never auto-charges.

🛡️

About code signing

The launcher is currently unsigned, so SmartScreen may warn about an unknown publisher. Click "More info → Run anyway". A certificate is being applied for.

🍎

No macOS support

Retail sticks are formatted NTFS, which macOS mounts read-only. For portable AI on a Mac, see U-DSH.
